# rMinecraft - راهنمای جامع پروژه و داکیومنت فنی (نسخه اختصاصی 1.12.2 در Rust)

این پروژه بازسازی کامل و بومی (Native) کلاینت ماینکرافت نسخه **1.12.2 (پروتکل 340)** با زبان برنامه‌نویسی **Rust** است.

---

## 🌟 اهداف و چشم‌انداز تجاری پروژه
- **هدف اصلی:** جایگزینی کامل کلاینت سنگین جاوا با یک کلاینت نیتیو و بهینه‌سازی شده در Rust بدون نیاز به نصب JVM.
- **عملکرد:** مصرف رم تا ۹۰٪ کمتر، رفع کامل لگ‌های Garbage Collection (GC stuttering)، لودینگ سریع چانک‌ها و اتصال پایدار به تمام سرورهای وانیلا و اختصاصی جاوا 1.12.2.
- **سازگاری کامل:** پیاده‌سازی مو به موی استانداردهای پوشه‌بندی و معماری رسمی `.minecraft` به طوری که کاربران فعلی بدون تغییر بتوانند از آن استفاده کنند.
- **تکسچرهای مدرن:** تطبیق خودکار و جایگزینی تکسچرهای قدیمی نسخه 1.12.2 با تکسچرهای بازطراحی شده و مدرن نسخه جدید ماینکرافت (Jappa Art).

---

## 📁 معماری پوشه‌بندی و ساختار رسمی (.minecraft)
پروژه دقیقاً منطبق بر ساختار رسمی ماینکرافت جاوا طراحی شده است:

```text
.minecraft/
├── launcher_profiles.json        # نگهداری پروفایل‌ها، اکانت‌های لوکال و توکن کلاینت
├── versions/
│   └── 1.12.2-rust/
│       ├── 1.12.2-rust.json      # مانیفست رسمی متادیتای نسخه، آرگومان‌ها و هش‌ها
│       └── rminecraft-client     # فایل باینری کامپایل‌شده کلاینت بومی Rust
├── assets/
│   ├── indexes/
│   │   └── 1.12.json             # شاخص رسمی دارایی‌های نسخه 1.12
│   └── objects/
├── skins/                        # محل ذخیره و کش اسکین‌های محلی (Local Skins)
├── capes/                        # محل ذخیره و کش شنل‌های محلی (Local Capes)
├── resourcepacks/
│   └── modern_textures_1.12.2.zip# پکیج تکسچرهای تبدیل‌شده مدرن برای 1.12.2
├── saves/                        # مپ‌ها و جهان‌های لوکال
└── logs/                         # لاگ‌های کلاینت و لانچر
```

## 🦀 ماژول‌ها و کریت‌های راست (Workspace Crates)

1. **`rminecraft-protocol`**:
   - پیاده‌سازی پروتکل شبکه 340 (Minecraft 1.12.2).
   - انکدر و دیکدر اختصاصی و سریع برای `VarInt`, `VarLong`, `MCString`, `Position`.
   - مدیریت فشرده‌سازی بسته‌ها با الگوریتم zlib در صورت فعال بودن ترشولد سرور.
   - محاسبه هش و تولید UUID استاندارد اکانت‌های لوکال بر مبنای MD5 (دقیقاً مشابه الگوریتم Java Offline Player UUID).
   - مدیریت ماشین وضعیت اتصال: `Handshaking -> Status -> Login -> Play`.

2. **`rminecraft-world`**:
   - ساختار داده چانک‌ها (`ChunkColumn` و `ChunkSection` در ابعاد ۱۶×۱۶×۱۶ و ارتفاع ۲۵۶).
   - سیستم مش‌ساز سه بعدی واکسل (`Mesher`) با قابلیت Hidden-face Culling در ۶ جهت جهت رندر با فریم‌ریت بالا.
   - رجیستری بلوک‌ها و استیت‌های 1.12.2 و نگاشت تکسچرها.

3. **`rminecraft-client`**:
   - کلاینت اجرایی نیتیو که تمامی سوییچ‌های خط فرمان رسمی لانچر را دریافت می‌کند:
     `--username`, `--uuid`, `--version`, `--gameDir`, `--assetsDir`, `--assetIndex`, `--skin`, `--cape`, `--server`.
   - ترد اختصاصی دریافت و ارسال پکت‌ها، پاسخ خودکار به پکت‌های KeepAlive و تایید تلپورت (`TeleportConfirm`).
   - فیزیک بازیکن: گرانش (`-0.08` در هر تیک)، اصطکاک و تشخیص برخورد با زمین.

4. **`rminecraft-launcher`**:
   - لانچر اختصاصی با پشتیبانی کامل از اکانت‌های آفلاین لوکال (Local Offline Accounts).
   - سیستم تزریق و مدیریت اسکین (`--skin`) و شنل (`--cape`) برای هر کاربر.
   - تولید و مدیریت خودکار فایل‌های کانفیگ رسمی `.minecraft`.

5. **`rminecraft-server`**:
   - سرور تست درون‌سازمانی با پروتکل 340 جهت تست اتصال، تبادل پکت‌ها، تولید چانک‌های واقعی زمین و تست چت زنده.

6. **`tools/texture_migrator.py`**:
   - اسکریپت پیشرفته پایتون که کلاینت 1.12.2 و نسخه مدرن را دانلود کرده، لیست‌های تکسچر را استخراج، نام‌های تغییریافته بعد از Flattening را تطبیق داده و ریسورس‌پک مدرن تولید می‌کند.

## 🚀 دستورات اجرا و تست (Quickstart)

### ۱. راه‌اندازی ساختار دایرکتوری ماینکرافت:
```bash
cargo run -p rminecraft-launcher -- --work-dir .minecraft init
```

### ۲. تعریف اکانت لوکال همراه با اسکین و شنل:
```bash
cargo run -p rminecraft-launcher -- --work-dir .minecraft add-account --username RustDev1 --skin .minecraft/skins/RustDev1.png --cape .minecraft/capes/RustDev1.png
cargo run -p rminecraft-launcher -- --work-dir .minecraft add-account --username RustDev2 --skin .minecraft/skins/RustDev2.png
```

### ۳. مشاهده لیست کاربران محلی:
```bash
cargo run -p rminecraft-launcher -- --work-dir .minecraft list-accounts
```

### ۴. اجرای سرور تست داخلی (جهت آزمایش پروتکل):
```bash
cargo run -p rminecraft-server &
```

### ۵. اجرای کلاینت و اتصال به سرور از طریق لانچر:
```bash
cargo run -p rminecraft-launcher -- --work-dir .minecraft launch --username RustDev1 --server 127.0.0.1:25565
```
